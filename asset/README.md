# Demo Data

`demo_case_1` and `demo_case_2` are selected demo subsets from the MVOIK-4D
dataset. They are included so the HAT-4D annotation workflow can be tested
without downloading the full dataset. The full dataset is available from the
[official MVOIK-4D page](https://huggingface.co/datasets/Lijiaxin0111/MVOIK-4D).
