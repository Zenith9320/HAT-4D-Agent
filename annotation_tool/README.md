# HAT-4D Annotation Tool

[English guide](README_eng.md) | [中文指南](README_ch.md) | [English UI guide](../docs/ui_README.md) | [中文 UI 指南](../docs/ui_README_ch.md)

This directory contains the Viser annotation frontend, the ROI/L4GM and SAM3D backends, and the optional QwenVL Human-Agent integration used by HAT-4D. Model checkpoints, the full dataset, caches, and generated workspaces are not included. The repository root contains two reviewed demo subsets under `asset/`; see [`asset/README.md`](../asset/README.md) for provenance and data-license terms.

Start with the language-specific guide above. Third-party source and license details are listed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
